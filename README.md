# 💱 Currency Converter App

A beautiful and responsive **Currency Converter** built with **React + Tailwind CSS**.  
It allows users to convert between currencies in real-time using live exchange rates fetched from **open.er-api.com**.

---

## 🚀 Features

- 🌍 Real-time exchange rate updates  
- 🔁 Swap between currencies instantly  
- 💡 User-friendly & clean UI  
- 🎨 Styled with Tailwind CSS  
- ⚡ Built using React hooks (`useState`, `useEffect`, `useId`)  
- 🧠 Custom hook for fetching exchange data

---

## 🧩 Tech Stack

- **React.js** – Frontend framework  
- **Tailwind CSS** – Styling  
- **open.er-api.com** – Free exchange rate API
